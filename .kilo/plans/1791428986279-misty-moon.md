## Phase 2: Docx Import Feature (New Functionality)

### Option A: Discord File Upload (Slash Command)
Add `/import-docx` command that:
- Accepts file attachment (.docx)
- Parses meeting minutes format from docx
- Shows preview of extracted tasks
- Creates tasks in Notion on confirmation

**Implementation:**
1. Add `python-docx` to requirements (already available)
2. Create `app/services/docx_parser.py` - extract text from docx, reuse `template_parser.py`
3. Add `/import-docx` command in `discord_client.py`
4. Handle Discord file attachment (max 25MB, but docx usually small)

### Option B: REST API Endpoint
Add `POST /api/v1/tasks/import-docx` endpoint that:
- Accepts multipart/form-data with docx file
- Returns preview or creates tasks directly
- Requires APP_TOKEN auth

### Option C: Local CLI Script
Standalone script to run locally:
```bash
python -m app.tools.import_docx meeting_minutes.docx
```
- Parses local file
- Creates tasks via Notion API directly
- No Discord bot needed
